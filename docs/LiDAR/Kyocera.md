# Kyocera (京セラ)

京セラは、カメラとLiDARを一体化した「Camera-LiDAR Fusion Sensor」を開発している。独自のセラミック技術を生かしたMEMSミラーも特徴。

## Key Technologies

### Camera-LiDAR Fusion Sensor
カメラの画像データとLiDARの点群データを、単一のハードウェア内で融合させるセンサー。

- **特徴**:
    - **視差ゼロ (Parallax-free)**: カメラとLiDARの光軸を一致させることで、視差のないデータ統合を実現。キャリブレーションの手間を省き、認識精度を向上。
    - **高解像度**: 世界最高クラスのレーザー走査密度 (角分解能 0.045°)。
    - **長距離検知**: 100m先でも高密度な測定が可能。

### MEMS Technology
セラミックパッケージ技術を応用した高耐久・高精度なMEMSミラーを自社開発。

## Specs (Reference)
- **角分解能**: 0.045° (High Density)
- **検知距離**: 100m (詳細スペックは開発段階による変動あり)
- **リリース目標**: 2025年3月までの製品化を目指す (発表時情報)。
