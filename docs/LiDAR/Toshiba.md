# Toshiba (東芝)

東芝は、独自のSiPM (Silicon Photomultiplier) 技術を用いたソリッドステートLiDARの開発に注力している。小型・低コストかつ長距離検知が可能なLiDARを目指す。

## Key Technologies

### SiPM LiDAR (Solid-State)
東芝独自の受光素子技術を用いたソリッドステートLiDAR。

- **方式**: Solid-State (Non-mechanical)
- **検出器**: SiPM (Silicon Photomultiplier) - 従来のAPDより高感度。
- **最大距離**: 200m (初期モデル) -> 300m (改良モデル)
    - 200m先でも高い反射率を持たない物体を検知可能。
    - **商用化目標**: FY2025 (2026年3月期) にソリッドステートモデルの製品化を目指す。
- **解像度**: 1200 x 80画素 (例) などの高解像度を実現。
- **特徴**:
    - **小型化**: 投光器と受光器を小型パッケージに統合。
    - **耐環境性**: ソリッドステート化による耐振動・長寿命。
    - **SAT技術**: Smart Accumulation Techniqueにより、太陽光ノイズ下でも遠距離検知を実現。

## Applications
- 自動運転 (Autonomous Driving)
- インフラ監視 (Infrastructure Monitoring)
- 定置型セキュリティ
