# Koito Manufacturing (小糸製作所)

自動車用照明機器で世界トップシェアを持つ小糸製作所は、ヘッドランプにLiDARを内蔵した統合システムの開発を推進している。

## Key Technologies

### Headlamp Integrated LiDAR
ヘッドランプユニット内にLiDARセンサーを格納するコンセプト。

- **メリット**:
    - **デザイン性**: 車両デザインを損なわずセンサーを搭載可能。
    - **メンテナンス**: ヘッドランプウォッシャーを利用して、LiDARセンサー面の泥や汚れを洗浄可能（全天候対応）。
    - **配置**: 車両の四隅（ヘッドランプ・テールランプ）に配置することで、360度センシングを実現。

## Partnerships

### Cepton (USA)
小糸製作所が出資・提携している主要パートナー。2025年1月7日に買収完了し、間接完全子会社化。

- **技術**: MMT (Micro Motion Technology) - ミラーレスでフリクションフリーな独自方式。
- **製品**: 車載用近距離・中距離LiDARを提供。

### Blickfeld (Germany)
ドイツのLiDARスタートアップとも協業。

- **技術**: MEMS Mirror LiDAR。
- **製品**: 超小型LiDARをヘッドランプ内に組み込む共同開発を実施。
