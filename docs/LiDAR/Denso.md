# Denso (デンソー)

Densoは、トヨタグループの主要サプライヤーとして、早くから車載LiDARの開発・量産を行っている。ミリ波レーダーやカメラと組み合わせた「Global Safety Package」の一部としてLiDARを提供しているほか、次世代の高性能LiDAR開発にも積極的。

## Key Technologies

### SPAD LiDAR (Solid-State)
次世代の高性能LiDARとして、SPAD (Single Photon Avalanche Diode) 検出器を用いたソリッドステートLiDARを開発中。

- **方式**: Solid-State
- **特徴**: 高感度なSPAD検出器により、微弱な反射光でも検知可能。
- **目標性能**: 200m以上の長距離検知、高解像度。
- **パートナー**: AMD (Xilinx) のFPGA/SoCを採用し、処理性能を向上。
- **リリース目標**: 2025年頃の市場投入を目指す (開発発表時情報)。

### FMCW LiDAR (Frequency Modulated Continuous Wave)
米Aeva社と提携し、次世代のFMCW LiDAR（4D LiDAR）の共同開発・市場投入を進めている。

- **特徴**: 距離と反射強度に加え、対象物の「速度」を直接計測可能。太陽光や他社LiDARとの干渉に強い。
- **パートナー**: Aeva

## Existing Products

### Mechanical / Scanning LiDAR (Legacy/Current)
Lexus LSやToyota Miraiなどの高度運転支援システム（Advanced Drive）に採用されているモデル。

- **用途**: 前方監視、周辺監視。
- **実績**: 長年の車載信頼性実績。
