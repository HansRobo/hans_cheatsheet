# Seyond (formerly Innovusion)

NIO（上海蔚来汽車）の車両に標準搭載されるなど、実績のある長距離LiDARメーカー。

## Automotive Long-Range

### Falcon
NIO ET7などに搭載されるイメージグレードの超長距離LiDAR。

- **リリース**: 2022年Q1 (NIO ET7出荷開始に合わせSOP)
- **波長**: 1550 nm
- **最大距離**: 500m (250m @ 10% reflectivity)
- **FOV**: 120° x 25°
- **ROI**: Foveated rendering的なROI設定が可能
- **解像度**: 0.09° x 0.08° (ROI), 0.18° x 0.24° (Non-ROI)
- **点群レート**: ~1,500 lines/sec equivalent scan lines
- **消費電力**: ~30 W
- **出典**: [Seyond Falcon Product Page](https://www.seyond.com/products/falcon)
